media-ui-react

A headless React component library for building media UIs. Ships behaviour, not styles — you own every pixel.

Headless Prop Getters Zero Styles

Introduction

media-ui-react provides three fully headless components — Grid, Lightbox, and ReelSwiper. They handle all behaviour: pagination, navigation, keyboard events, scroll detection, video autoplay. You supply the markup and CSS.

Independent by design. This package has zero imports from media-core or media-react. Components receive data and callbacks purely as props — they don't know Pexels or the SDK exist.

Headless Pattern

Components expose prop-getter functions that return the correct event handlers, aria attributes, and roles. Spread them onto your own elements:

// The component gives you prop-getters:
const { getContainerProps, getItemProps, getLoadMoreProps } = useGrid({ items });

// You spread them onto YOUR markup:
<div {...getContainerProps()} className="my-grid">
  {visibleItems.map((item, i) =>
    <div {...getItemProps(i)} className="my-item">
      ...
    </div>
  )}
</div>
<button {...getLoadMoreProps()} className="my-btn">Load more</button>

Or use the higher-level component with render* props for full markup control:

<Grid
  items={photos}
  renderContainer={(props, children) => (
    <ul {...props} className="photo-grid">{children}</ul>
  )}
  renderItem={(photo, getItemProps) => (
    <li {...getItemProps()} className="photo-card">
      <img src={photo.src.medium} />
    </li>
  )}
  renderLoadMore={(props) => (
    <button {...props} className="load-more-btn">Load More</button>
  )}
/>

Grid

Paginated grid with load-more. Zero layout opinions.

import { Grid } from "media-ui-react";

<Grid
  items={photos}
  renderItem={(photo, getItemProps) => (
    <div {...getItemProps()}>
      <img src={photo.src.medium} onClick={() => openLightbox(photo)} />
    </div>
  )}
/>

Props

PropTypeDescription
itemsT[]requiredAny array of items. Generic — works with any shape.
renderItem(item, getItemProps) => ReactNoderequiredRender each item. Spread getItemProps() for a11y roles.
pageSizenumberoptional · 12How many items to show per page.
renderContainer(props, children) => ReactNodeoptionalOverride the wrapping element. Default is a plain div.
renderLoadMore(props) => ReactNodeoptionalOverride the load more button. Default is a plain button.

Prop Getters

getContainerProps() Returns role="list" for the grid wrapper.
getItemProps(index) Returns role="listitem" and key for each item.
getLoadMoreProps() Returns onClick, aria-label, and type="button".

Lightbox

Full-screen image overlay with navigation, keyboard support, and download.

import { Lightbox } from "media-ui-react";

const [selectedIndex, setSelectedIndex] = useState<number | null>(null);

{selectedIndex !== null && (
  <Lightbox
    items={photos.map((p) => ({ id: p.id, imageUrl: p.src.large }))}
    selectedIndex={selectedIndex}
    isOpen={true}
    onClose={() => setSelectedIndex(null)}
    onDownload={(item) => sdk.trackDownload(item)}
    renderOverlay={(props, children) => (
      <div {...props} className="lb-overlay">{children}</div>
    )}
    renderImage={(props, item) => (
      <img {...props} src={item.imageUrl} className="lb-image" />
    )}
    renderPrevButton={(props) => (
      <button {...props} className="lb-btn lb-prev">◀</button>
    )}
    renderNextButton={(props) => (
      <button {...props} className="lb-btn lb-next">▶</button>
    )}
    renderCloseButton={(props) => (
      <button {...props} className="lb-btn lb-close">✕</button>
    )}
    renderDownloadButton={(props) => (
      <button {...props} className="lb-btn lb-download">Download</button>
    )}
  />
)}

Props

PropTypeDescription
items{id, imageUrl}[]requiredFlat array of lightbox items.
selectedIndexnumberrequiredIndex of the initially active item.
isOpenbooleanrequiredControls visibility.
onClose() => voidrequiredCalled when overlay or close button clicked.
onDownload(item) => voidoptionalCalled after download completes.
renderOverlay(props, children) => ReactNodeoptionalOverride the backdrop element.
renderImage(props, item) => ReactNodeoptionalOverride the image element.
renderPrevButton(props) => ReactNodeoptionalOverride previous button.
renderNextButton(props) => ReactNodeoptionalOverride next button.
renderCloseButton(props) => ReactNodeoptionalOverride close button.
renderDownloadButton(props) => ReactNodeoptionalOverride download button.

Prop Getters (via useLightbox)

getOverlayProps() role="dialog", aria-modal, aria-label, onClick to close.
getImageProps() role="img", onClick stops propagation.
getPrevButtonProps() onClick prev, aria-label="Previous image", type="button".
getNextButtonProps() onClick next, aria-label="Next image", type="button".
getCloseButtonProps() onClick close, aria-label="Close lightbox", type="button".
getDownloadButtonProps(onDownload, item) Handles blob fetch + browser download + fires onDownload callback.

Keyboard Support

Built into useLightbox automatically — no extra setup needed:

  • Escape — closes the lightbox
  • ArrowRight — next image
  • ArrowLeft — previous image
Portal rendering. Lightbox renders via createPortal into document.body — it always appears above other content regardless of z-index stacking contexts in your app.

ReelSwiper

Vertical snap-scroll video reel with active-item autoplay.

import { Reel } from "media-ui-react";

const reelItems = videos.map((v) => ({
  id: v.id,
  videoUrl: v.videoUrl?.replace(/[[\]]/g, ""), // clean encoded brackets
}));

<Reel items={reelItems} />

Props

PropTypeDescription
items{id: number, videoUrl: string}[]requiredVideo items. Only videoUrl is needed.

Behaviour

  • Each item snaps to full viewport height (scroll-snap-type: y mandatory)
  • Active index tracked via scroll position
  • Only the active video has autoPlay — others are paused
  • All videos are muted, loop, playsInline (required for browser autoplay)
Height requirement. The Reel container is height: 100vh. Its parent must not have overflow: hidden or a fixed height smaller than the viewport.

Video URL Gotcha

Pexels video URLs sometimes contain encoded brackets. Always clean them before passing:

videoUrl: v.videoUrl?.replace(/[[\]]/g, "")

useGrid

The hook powering Grid. Use directly if you want full control over the rendered markup.

import { useGrid } from "media-ui-react";

const {
  visibleItems,
  hasMore,
  loadMore,
  getContainerProps,
  getItemProps,
  getLoadMoreProps,
} = useGrid({ items, pageSize: 12 });
Return valueTypeDescription
visibleItemsT[]Current page slice of items.
hasMorebooleanTrue if more items exist beyond current page.
loadMore() => voidIncrements visible count by pageSize.
getContainerProps() => objectProps for the grid wrapper.
getItemProps(index) => objectProps for each item.
getLoadMoreProps() => objectProps for the load more trigger.

useLightbox

The hook powering Lightbox. Use directly for fully custom lightbox markup.

import { useLightbox } from "media-ui-react";

const {
  currentIndex,
  next,
  previous,
  getOverlayProps,
  getImageProps,
  getPrevButtonProps,
  getNextButtonProps,
  getCloseButtonProps,
  getDownloadButtonProps,
} = useLightbox({
  initialIndex: selectedIndex,
  totalItems: items.length,
  onClose,
});
Return valueTypeDescription
currentIndexnumberCurrently active item index.
next() => voidGo to next item (wraps around).
previous() => voidGo to previous item (wraps around).
getOverlayProps() => objectProps for the backdrop.
getImageProps() => objectProps for the image.
getPrevButtonProps() => objectProps for prev button.
getNextButtonProps() => objectProps for next button.
getCloseButtonProps() => objectProps for close button.
getDownloadButtonProps(onDownload, item) => objectProps for download button. Handles blob fetch internally.

Media SDK

A headless, framework-agnostic media SDK powered by the Pexels API. Search photos and videos, track events, and build any UI on top.

TypeScript Zero UI Pexels API React Wrapper

Overview

Media SDK is a monorepo of packages that let you build media-rich applications without coupling your data layer to your UI layer.

⚙️

media-core

Framework-agnostic SDK. Pure TypeScript, no React, no DOM.

⚛️

media-react

React wrapper. Provider + hooks. No business logic.

🧩

media-ui-react

Headless UI components. Grid, Lightbox, Reels. No shipped styles.

Architecture

Dependency direction is strictly enforced. Components never import core; core never imports React.

app ──────────────────► media-react ──► media-core
app ──────────────────► media-ui-react

// media-ui-react never imports media-core or media-react
// media-core has zero React/DOM imports

Installation

Clone the repo and install from the root. All packages are workspace-linked automatically.

git clone https://github.com/armanankur/media-sdk-app
cd media-sdk-app
npm install
npm run build

Add your Pexels API key to apps/web-app/.env:

VITE_PEXELS_API_KEY=your_key_here

MediaSDK

The top-level class from media-core. Wires together the API client, cache, and event emitter.

import { MediaSDK } from "media-core";

const sdk = new MediaSDK({ apiKey: "your_key" });

Constructor

OptionTypeDescription
apiKeystringYour Pexels API key. Never exposed beyond this config call.

Methods

MethodReturnsDescription
search(query, page?, perPage?)Promise<any>Search photos. Cached by query+page+perPage.
curated(page?, perPage?)Promise<any>Trending/curated photos. Cached.
videos.search(query, page?, perPage?)Promise<any>Search videos.
videos.popular(page?, perPage?)Promise<any>Popular videos.
trackView(item)voidEmits a view event.
trackDownload(item)voidEmits a download event.

Caching

search() and curated() results are cached in memory. Repeated calls with identical params skip the network entirely.

PexelsClient

Low-level API client. Used internally by MediaSDK — you typically don't need to use this directly.

import { PexelsClient } from "media-core";

const client = new PexelsClient("your_api_key");
MethodDescription
search(query, page?, perPage?)Search photos
curated(page?, perPage?)Curated photos
getPhoto(id)Single photo by ID
videosSearch(query, page?, perPage?)Search videos
videosPopular(page?, perPage?)Popular videos

Event Emitter

The SDK ships a simple pub/sub emitter. view and download are the built-in event types. A default logger is registered automatically.

// Default logger fires automatically (no setup needed):
// [MEDIA VIEW] { id: 123, ... }
// [MEDIA DOWNLOAD] { id: 456, ... }

// Emit events in your app:
sdk.trackView(photo);
sdk.trackDownload(photo);

// Subscribe to events independently:
sdk.events.on("view", (payload) => {
  // send to analytics, etc.
});

// Unsubscribe:
sdk.events.off("view", myListener);

MediaEventEmitter API

MethodDescription
on(event, listener)Subscribe to an event
off(event, listener)Unsubscribe a listener
emit(event, payload)Fire an event with a payload

MemoryCache

A generic in-memory key-value cache. Used internally by MediaSDK.

import { MemoryCache } from "media-core";

const cache = new MemoryCache<string>();
cache.set("key", "value");
cache.get("key");   // "value"
cache.has("key");   // true
cache.delete("key");
cache.clear();

MediaProvider

From media-react. Initialises MediaSDK and makes it available to the React tree via context.

import { MediaProvider } from "media-react";

ReactDOM.createRoot(document.getElementById("root")!).render(
  <MediaProvider apiKey={import.meta.env.VITE_PEXELS_API_KEY}>
    <App />
  </MediaProvider>
);
PropTypeDescription
apiKeystringrequiredPexels API key. Read from env var on Vite.
childrenReactNoderequiredYour app tree.

useMedia()

Hook that returns the MediaSDK instance. Must be called inside MediaProvider.

import { useMedia } from "media-react";

function MyComponent() {
  const sdk = useMedia();

  const [photos, setPhotos] = useState([]);

  useEffect(() => {
    sdk.curated().then((r) => setPhotos(r?.photos ?? []));
  }, []);
}

Throws an error if called outside MediaProvider — no null-checking needed.
